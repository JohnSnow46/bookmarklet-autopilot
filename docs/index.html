Oracle Bookmarklets

Automate the repetitive scan → search → fill → save → print routine with plain browser bookmarks. No installation, no extensions.

1. Check that bookmarklets work on your computer

Create a bookmark whose URL is exactly javascript:alert('ok') and click it on any web page.

A dialog saying ok means you can continue. If nothing happens, your IT policy blocks bookmarklets: stop here, that is a decision, not a bug.

2. Add the bookmarklets

Either drag a button to the bookmarks bar (Ctrl+Shift+B shows the bar), or press Copy code, create a new bookmark and paste the whole line into its URL field.

3. Use them

  1. Open the application page and click Learn. Follow the bar at the top: Ctrl+click each element it asks for; a plain click works normally, so you can do the real process while teaching it. Use Skip for optional steps, Back to undo.
  2. Check the summary, type the text to append and the list option, save.
  3. Optional: use Validate to add checks (for example "this field equals that field").
  4. Every day: scan a code into the search field, click Auto, confirm the system print dialog.
  5. If the application reloads the whole page between steps, click Auto again after each reload; it continues where it stopped.
  6. If the browser blocks the print tab, allow pop-ups for the site.
Practise first on the test mock. It imitates the process and shows an event log. Variants: no User list, form in an iframe, full page reloads.

Safety

A bookmarklet runs with the full rights of the page you click it on, so read what you paste. The code is short and never talks to the network; the build refuses to produce code that does. Compare the SHA-256 of what you copied with the value shown under each button.

Get your manager's / IT's approval before using automation on a company system. Nothing learned is ever sent anywhere: it lives in this browser's localStorage. Never share a configuration export outside the company.
