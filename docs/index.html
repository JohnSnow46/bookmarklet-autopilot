Bookmarklet Autopilot

Record a repetitive routine in any web app once, then replay it with one click. Plain browser bookmarks: no installation, no extensions, nothing leaves the browser.

New here? Follow the step-by-step guide with screenshots.

1. Check that bookmarklets work in your browser

Create a bookmark whose URL is exactly javascript:alert('ok') and click it on any web page.

A dialog saying ok means you can continue. If nothing happens, bookmarklets are disabled in this browser (for example by a managed browser policy) and the project cannot work there.

2. Add the bookmarklets

Either drag a button to the bookmarks bar (Ctrl+Shift+B shows the bar), or press Copy code, create a new bookmark and paste the whole line into its URL field.

3. Use them

  1. Open the web app and click Record. Do the routine once, normally, then press Stop and review and answer the short questions (steps to remove, how to pick list values, before which steps to ask "Save?").
  2. Run Dry run on each screen: it shows which recorded steps it can find and clicks nothing.
  3. Every time after that: enter the input (type it or scan a barcode), click Play. For many items in a row use Series.
  4. Optional: use Validate to add checks (for example "this field equals that field").
  5. If the app reloads the whole page between steps, click Play again after each reload; it continues from what it sees.
  6. If the browser blocks a new tab the routine opens, allow pop-ups for the site.

Learn and Auto are the advanced variant for a fixed lookup → copy → fill → save → print workflow, taught step by step with Ctrl+click.

Practise first on the demo app. It imitates a typical routine and shows an event log. Variants: no User list, form in an iframe, full page reloads.

Safety

A bookmarklet runs with the full rights of the page you click it on, so read what you paste. The code is short and never talks to the network; the build refuses to produce code that does. Compare the SHA-256 of what you copied with the value shown under each button.

Nothing recorded or learned is ever sent anywhere: it lives in this browser's localStorage. An export contains the recording in readable form, so share it only with people who should see it.
